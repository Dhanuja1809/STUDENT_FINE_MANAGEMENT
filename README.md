Module Descriptions
1. Admin Module 🛠️
Payment Overview: Centralized dashboard to view all recorded student payments across the institution.
Advanced Data Filtering: Powerful search capabilities to filter transactions by Fine Type, Student ID, or specific Date Ranges.
Full Record Management: Administrative authority to Add, Update, or Delete payment entries to maintain ledger accuracy. 

2. Cashier Module 💰
Transaction Processing: Streamlined interface for recording new fine payments in real-time.
Record Maintenance: Essential tools to modify or remove payment records in case of data entry errors. 

3. Student Module 🎓
Personal Profile: Secure access for students to view and update their basic information.
Financial Transparency: Dedicated view for students to track their personal transaction history and current outstanding balance. 

4. Core System Features 🔑
Role-Based Access Control (RBAC): A secure authentication system that automatically redirects users to their specific functional menu based on their login credentials.
User Registration: Intuitive onboarding process for new student accounts.
